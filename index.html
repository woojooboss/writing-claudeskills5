5개의 스킬

각 스킬이 글쓰기의 한 가지 약점을 정확히 겨냥합니다.

Dumbify

복잡한 아이디어는 그대로 지키면서 중학생도 읽을 수 있는 가독성으로 다시 씁니다. 전문용어를 걷어내고 겹겹이 꼬인 문장을 끊되, 내용을 단순화하진 않습니다.

"장황함"을 고칩니다
Storytelling

BUT/THEREFORE 패턴과 긴장–전환–보상 구조로 글을 짭니다. 유튜브에서 검증된 스토리텔링 역학을 글에 그대로 적용합니다.

"지루함"을 고칩니다
Viral-hooks

첫 문장을 4가지 훅 킬러(지연·혼란·무관함·무관심) 기준으로 진단하고 다시 씁니다. 플랫폼별 타이밍 가이드까지 포함합니다.

"넘겨짐"을 고칩니다
Anti-AI-Writing

부정 병렬, 재활용된 상투구 같은 'AI가 쓴 티' 패턴을 제거합니다. 5가지 질병을 짚어내고 구체성 사다리를 돌려 사람의 글로 되돌립니다.

"AI 티남"을 고칩니다
Voice-DNA

당신의 실제 글·대본 20개를 분석해 목소리 프로필(문장 패턴·시그니처 표현·훅·CTA)을 뽑아냅니다. 다운로드가 아니라, 약 2분 만에 직접 만드는 스킬입니다.

"당신답게" 만듭니다

설치 방법

세 가지 방법,
가장 빠른 건 10초.

1

붙여넣기 10초

스킬 내용을 복사해, 고치고 싶은 초안과 함께 클로드 채팅에 그대로 붙여넣습니다. 설치 없이 바로 사용.

2

한 번 업로드 Pro · Max

설정 → 사용자화 → 스킬에서 한 번만 등록하면 모든 대화에서 영구적으로 쓸 수 있습니다.

3

Claude Code

개발자라면 터미널에서 GitHub 저장소를 받아 설치합니다. git clone 후 스킬 폴더 연결.
