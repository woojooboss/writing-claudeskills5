# 클로드의 글쓰기를 고치는 5가지 스킬

클로드는 잠재력만 보면 훌륭한 작가지만, 기본값으로는 평범합니다. 자꾸 얼버무리고, 과하게 설명하고, "단순히 ~가 아니라 ~입니다" 같은 틀에 기대고, 무엇보다 **당신처럼** 쓰지 못합니다. 이 다섯 개의 스킬은 그 문제를 하나씩 고칩니다.

스킬은 이야기처럼 이어집니다: **장황함 → 지루함 → 훅 없음 → AI 티남 → 당신답지 않음.**

| # | 스킬 | 무엇을 고치나 |
|---|------|--------------|
| 1 | **dumbify** | 어떤 글이든 중학생 수준 읽기 난도로 다시 씁니다 — 인지 부담은 낮추고 리텐션은 높이되, 아이디어를 유치하게 만들지 않습니다. |
| 2 | **storytelling** | 훅 이후에도 시선을 붙잡는 '이야기' 구조로 글을 짭니다. 나열식 팁이 아니라 긴장–전환–보상. |
| 3 | **viral-hooks** | 모든 도입부를 망치는 네 가지를 기준으로 당신의 훅을 진단하고, 먹히는 첫 문장으로 다시 씁니다. |
| 4 | **anti-ai-writing** | 글에서 'AI 티'가 나게 만드는 흔적을 걷어냅니다 — 부정 병렬, 재활용된 상투구, 과한 강조. |
| 5 | **voice-dna** | 당신의 최근 글 약 20개로 클로드에게 *당신의* 목소리를 가르칩니다. 직접 만드는 스킬입니다 — [`voice-dna/`](voice-dna/) 참고. |

1~4번은 그대로 받아 쓰는 폴더입니다. 5번은 당신의 콘텐츠로 약 2분 만에 직접 만듭니다(가이드: [`voice-dna/README.md`](voice-dna/README.md)).

---

## 처음이신가요? — 스킬이 대체 뭔가요

**스킬(Skill)이란 `SKILL.md` 파일 하나가 들어 있는 폴더**입니다. 그 안에는 '이렇게 써라'라는 글쓰기 지침이 담겨 있습니다. 클로드는 파일 맨 위의 `description:` 줄을 읽고, 상황에 맞을 때 **알아서** 그 지침을 적용합니다. 이름을 불러 호출할 필요가 없습니다.

**개발자가 아니어도 됩니다. Claude Code가 없어도 됩니다.** 아래 세 가지 방법 중 본인에게 맞는 걸 고르세요. 쉬운 것부터 적었습니다.

---

## 사용법 (쉬운 순서대로)

### 방법 1. 그냥 붙여넣기 — 무료 플랜 포함 어디서나 (10초)

설치가 전혀 필요 없는 방법입니다.

1. 받은 zip의 압축을 풀고, 원하는 스킬 폴더 안의 `SKILL.md`를 메모장·텍스트 편집기로 엽니다. (voice-dna는 `README.md`)
2. **내용 전체를 복사**합니다.
3. 평소처럼 클로드 채팅을 열고, 아래 틀에 맞춰 붙여넣습니다.

```
아래 글쓰기 규칙에 따라 내 초안을 다시 써 줘. 그리고 무엇을 왜 바꿨는지 알려 줘.

[여기에 스킬 내용을 붙여넣으세요]

내 초안:
[여기에 당신의 캡션 / 대본 / 게시물을 붙여넣으세요]
```

여러 개를 겹쳐 쓰고 싶다면? 같은 채팅에 dumbify → storytelling → anti-ai-writing 순서로 차례차례 붙여넣으면 됩니다.

### 방법 2. 클로드 앱에 한 번만 설치 — 그다음부턴 자동 (Pro / Max)

스킬을 한 번만 업로드해 두면, 글을 써 달라고 할 때마다 클로드가 알아서 적용합니다. 모든 채팅에서요.

1. 클로드에서 **설정(Settings) → Capabilities**로 가서 **Code execution and file creation(코드 실행 및 파일 생성)**을 켭니다.
2. **설정 → Customize → Skills → Upload**로 가서, 스킬 폴더를 **zip으로 압축해** 하나씩 올립니다.
   - 한 번에 하나씩 올리세요. `dumbify/` 폴더를 압축할 때 **폴더가 zip의 맨 위에 오도록** 압축한 뒤 올리고, 그다음 `storytelling/`, 이런 식으로 반복합니다.
   - (이미 받은 개별 zip 파일 `dumbify.zip`, `storytelling.zip` … 을 그대로 올려도 됩니다.)
3. 클로드에게 무언가를 써 달라거나 고쳐 달라고 하세요. 클로드가 스킬 설명을 읽고 자동으로 적용합니다.

> 커스텀 스킬 업로드는 코드 실행이 켜진 **Pro 또는 Max 플랜**에서 가능합니다.

### 방법 3. Claude Code (개발자용)

압축을 푼 `dumbify/`, `storytelling/`, `viral-hooks/`, `anti-ai-writing/` 폴더를 Claude Code 스킬 디렉터리 `~/.claude/skills/`에 복사한 뒤, 새 세션을 시작하면 자동으로 인식됩니다.

직접 옮기기 번거롭다면 Claude Code에 이렇게 부탁해도 됩니다.

```
방금 압축을 푼 글쓰기 스킬 폴더들을 내 Claude Code 스킬 디렉터리(~/.claude/skills/)에
설치해 줘. 그리고 적용되도록 어떻게 재시작하면 되는지 알려 줘.
```

**그다음 voice-dna 만들기:** [`voice-dna/README.md`](voice-dna/README.md)를 따라 당신의 글 약 20개를 붙여넣으면 됩니다. 결과물은 채팅에 붙여넣어(방법 1) 쓰거나, 스킬로 업로드해(방법 2) 재사용할 수 있습니다.

---

## 어떻게 함께 작동하나

각 스킬에는 **작성 모드(처음부터 쓰기)**와 **점검 모드(이미 쓴 초안을 진단·교정)**가 있어, 클로드가 이미 써 놓은 글에도 돌릴 수 있습니다. 서로 충돌하지 않도록 설계되어 있습니다.

- **dumbify**는 단어를 쉽게 하되, **storytelling**이 만든 리듬을 납작하게 만들지 않습니다.
- **storytelling**은 첫 문장을 **viral-hooks**에 넘깁니다.
- **viral-hooks**는 A–B 대비를 일부러 쓰고, **anti-ai-writing**은 *보상이 구체적일 때만* 그걸 허용합니다("속 빈 대비 vs 값을 치른 대비" 테스트).
- **voice-dna**는 나머지 셋에게 흉내 낼 진짜 목소리를 줍니다. 기계적 규칙으로 돌아가지 않도록요.

자연스러운 전체 흐름: 초안 → **storytelling/viral-hooks**(구조와 첫 문장) → **dumbify**(부담 낮추기) → **anti-ai-writing**(최종 필터) → 그 모든 걸 **voice-dna**에 통과.

## 자주 묻는 질문

**Q. 무료 클로드에서도 되나요?**
방법 1(붙여넣기)은 무료 플랜 포함 어디서나 됩니다. 방법 2(영구 설치)는 Pro·Max에서, 방법 3은 Claude Code 환경에서 동작합니다.

**Q. 한국어 글에도 잘 맞나요?**
네. 한국어 글에 맞는 예시와 표현으로 다듬어 두었습니다.

**Q. 어떤 스킬부터 써야 하나요?**
글이 빽빽하면 dumbify, 지루하면 storytelling, 첫 문장이 약하면 viral-hooks, AI 티가 나면 anti-ai-writing. 잘 모르겠으면 anti-ai-writing을 마지막 필터로 한 번 돌려 보세요.
